# content/

The long-term store. The app in `app/` captures; this folder keeps.

Everything here is plain Markdown with a small front-matter block, so it can be
read by a person, by git, and by Claude. When you say "add this to my app",
this is where it goes.

| Folder          | What                                                        |
| --------------- | ----------------------------------------------------------- |
| `brain-dumps/`  | One file per dump. Spoken or typed. Raw first, cleaned later. |
| `library/`      | Books, articles, people, tools — anything that shaped you.   |
| `program/`      | The 12 chapters and how they evolve.                         |
| `voice/`        | Tone of voice. How you actually talk. Built up over time.    |
| `business/`     | The brief, the offer, the audience — as they get decided.    |

The app's **Export → Download .zip** produces exactly this layout. Unzip it at
the repo root and commit.
